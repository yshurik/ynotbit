# ynotbit — Signal + Shield

Выбранный вариант: светлый авиапочтовый конверт, сгибы в форме Y и тёмный щит на их стыке. Щит обозначает защищённую переписку; красные и синие полосы сохраняют узнаваемую тему airmail.

Это готовые графические ресурсы для подключения к приложению. Текущие `assets/ynotbit.svg`, `assets/ynotbit.icns` и код приложения не заменены.

PNG/SVG: **16, 20, 24, 32, 40, 48, 64, 96, 128, 256, 512, 1024 px** для приложения и окна. Иконка приложения имеет почти квадратный силуэт; иконка окна — более широкий конверт с увеличенным относительно его высоты щитом.

Каждый ICO содержит 10 кадров: 16, 20, 24, 32, 40, 48, 64, 96, 128, 256 px. ICNS содержит стандартные 16, 32, 128, 256, 512 pt в масштабах 1× и 2×. PNG для Linux: 16–512 px; SVG — `scalable/apps/ynotbit.svg`.

## Оптические версии

- **16–20 px:** сплошной щит, без замочной скважины; упрощённый конверт без тонкого контура и тени.
- **24–32 px:** скважина заменена прямоугольной прорезью шириной в один пиксель; геометрия привязана к сетке.
- **40 px:** переходная версия с простой прорезью.
- **48–1024 px:** щит с полноценной замочной скважиной, мягкий оттенок бумаги, тонкий внешний контур.
- **Retina:** логический размер определяет детализацию. Например, `icon_16x16@2x.png` — упрощённая 16-point композиция в 32 физических пикселях, а `icon_32x32.png` — самостоятельная композиция для 32 point.

Для Qt выбирайте отдельные растровые кадры через `QIcon::addFile()` либо готовый ICO; уменьшение единственного большого SVG не воспроизводит оптические поправки. Система Linux также может предпочесть SVG, поэтому фактический выбор размера стоит проверить после подключения к конкретному окружению.

## Цвета и логотип

Чернильный: `#19334B`; красный: `#DB5149`; синий: `#2871B8`; светлая бумага: `#FFF9EC`. Полупрозрачных фонов вне силуэта нет, кроме небольшой тени крупных иконок.

`ynotbit-lockup.svg` содержит редактируемый текст Helvetica/Arial/sans-serif. Это дополнительный вариант компоновки названия; текст не переведён в кривые и может отличаться при подстановке шрифта. Сама иконка от шрифтов не зависит.

## Проверка и воспроизведение

Размеры, альфа-канал и прозрачные углы всех 34 основных PNG проверены. Оба ICO разобраны, все 20 встроенных PNG декодированы. ICNS создан штатным `iconutil`. Предпросмотр проверен на светлом и тёмном фоне, малые иконки дополнительно показаны с увеличением 4× без сглаживания. Проверка в запущенном приложении на трёх ОС не проводилась.

В родительском каталоге исследования находятся `build-icons.cjs` и `finalize.cjs`. Требуются Node.js, пакет `sharp` и macOS `iconutil` для сборки ICNS:

```sh
ICON_FAMILY=protected node build-icons.cjs
node finalize.cjs
```

Первый скрипт воспроизводит три варианта защищённого Signal; второй выделяет выбранный Shield, создаёт обзор и проверяет файлы. Растровые концепты созданы встроенным image_gen, финальные ресурсы построены из редактируемой SVG-геометрии. Ключевой запрос для концепта: Signal airmail envelope, navy Y-shaped fold, integrated shield with an ivory keyhole, red/blue edge stripes, protected private mail.

Платформенные ориентиры: [Apple — App icons](https://developer.apple.com/design/human-interface-guidelines/app-icons), [Microsoft — App icon construction](https://learn.microsoft.com/en-us/windows/apps/design/iconography/app-icon-construction), [freedesktop — Icon Theme Specification](https://specifications.freedesktop.org/icon-theme/). Для существующего desktop-проекта подготовлен ICNS, без слоистого проекта Icon Composer.
