## Fixes

- **The Windows version starts its node again.** 0.8.0 started its node with a call Windows refused, and the app said "Node: The parameter is incorrect." and ran with no node: no connections, nothing sent, nothing received. If you use 0.8.0 on Windows, install this version. macOS and Linux were not affected.
- A line the node writes to its error output no longer carries the carriage return Windows adds, so the "Node: …" message reads the same on every system.

## Also

- Nothing in the tests of 0.8.0 had started a node through the app on Windows. The smoke test now starts it with the network on and waits for it, on every system and on the Windows package, and the node supervisor has its tests on Windows, with the real node among them.
