## New

- **Nicknames.** An address can have a short name: `@ben` for a person, `/bot` for a bot or a service, `#room` for a chan. A *nickbot* keeps them, a small service that maps nicknames to addresses and back (docs/nickbot.md in the repository describes it). Settings → Nickbots lists up to five, the first is the default, and each has a colour. A nickname shows wherever its address does (the letter list, the reader, Contacts, the chat list), in the colour of the nickbot that vouched for it. An identity can ask for a nickname. Contacts → **Find people** asks a nickbot for a nickname, an address or a name; the answer takes a few minutes. Lookups are sent from a shared chan, not from one of your identities, so a nickbot does not see which identity asks, and Contacts → Check nicknames asks about the whole address book only when you say so.
- **Two contacts to start with.** Every mailbox begins with `/echobot`, a bot that answers a chat with what you sent (say `/help` to it), and `/nickbot`, the default nickbot. A letter to the echo bot is answered with a letter that says where chats are.
- **The address book is a table.** Address (with its identicon), Nickname and Local name, sorted by a click on a header, with its actions in a toolbar. The add contact dialog suggests a name made from the address. A contact whose name starts with `/` is a bot: **Write** opens a chat with it, and a new **Chat** button starts one with anyone. Identities are the same table.
- **People you deal with join the address book.** Once, when a mailbox from before opens: everyone you wrote to and everyone who wrote to your Inbox, named from the address. A contact you delete stays deleted.
- **Subscriptions follow the people you deal with.** Adding a contact, writing to someone or hearing from them (not chans) makes a hidden subscription, so their broadcasts are not missed. It is listed under Subscriptions when they first post, or when you subscribe on purpose. Subscriptions are sorted by their newest post.
- **Import from PyBitmessage.** File → Import PyBitmessage data… brings identities, chans, the address book, subscriptions and letters into the open vault and mailbox, with a count for each kind, a progress bar and a report. PyBitmessage's files are only read, so it can keep running. A mailbox that has not dealt with it is offered the import when it opens.
- **ynotbit lives in the notification area.** An icon in the macOS menu bar, the Windows tray or the Linux tray, with Show/Hide, New letter, New chat, Settings and Quit. Closing the window hides it and ynotbit keeps running; starting it again shows the running window. Where there is no tray (stock GNOME) closing quits, as before.
- **Unread counts.** The number of unread letters and chats on the Dock, taskbar or launcher icon, and on the Chats, Inbox, Channels and Subscriptions buttons of the left rail. Settings → Notifications has a switch for the icon.
- **Sounds for new mail and new chat,** with themes you add in Settings; one, "retro", comes with the app.
- **Mark all as read** in the right-click menu of the list of letters.
- **The File menu is in groups,** with recent vaults and mailboxes, and opening a vault closes the open one instead of refusing.
- **Composers and pop-out letters are windows of their own:** writing a letter no longer locks the main window.

## Faster

- **Broadcasts.** A broadcast is matched to its subscription by its tag instead of by trying every subscription: 100 broadcasts against 8,000 addresses took 32 seconds and take 0.3.

## Network

- **A stalled node is started again.** A node whose status stopped for two minutes is restarted, never twice in five minutes.
- **A peer you named is kept.** A dropped link to a peer given to the node with `-P` is tried again every 5 to 30 seconds for ever; it used to wait up to an hour.

## Fixes

- The sender's address in the reader is no longer cut after `BM-` when there is room for it.
- On Windows a second launch finds the first however the path of the data folder is spelled.
- On GNOME the busy cursor no longer stays after a click in the tray menu.

## Also

- **The data folder is named ynotbit** (it was NotbitDesktop). The first start moves the old folder and its settings over; if the folder cannot be moved, the old one is used.
- **Linux:** an AppImage or a build nobody integrated makes its launcher entry and icons on first run, and the panel names the app `ynotbit-<version>`.
- **For people who run bots:** `libbmbot`, a bot library with a C ABI that Go and Python use; `chat_responder`, which runs for months with no Qt, and a Docker image for it (docs/chat-responder.md); the nickbot service in Go; and `bm_vanity`, a search for an address with a word in it, about 100 million keys a second on a server with AVX-512.
- Under the hood the vault, the mailbox, the delivery engine and the handling of the node moved into a library with no Qt (`bmclient`).
