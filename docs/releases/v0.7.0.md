## New

- **Chats.** One-to-one conversations in the main window, with Markdown, delivery ticks and unread counts. A chat belongs to one of your identities; the same person under two identities is two chats. A chat travels as an ordinary Bitmessage message with an empty subject, kept 24 hours.
- **One dialog for a new vault.** It makes the vault and its first identity together, from random keys or a secret phrase, with an optional search for a shorter address. New identities are made in the same dialog.
- **Settings** is a page of the main window (the gear in the rail): Network, Storage, Sending, Appearance, Notifications and Security.
- **The reader** scrolls the subject, details and body as one. The top bar names the version.

## Faster

- **Sending.** Proof of work runs on every core but one, and on the GPU where a usable one is found (Metal on macOS, OpenCL elsewhere).
- **Big hex letters** open about ten times faster.

## Network

- ynotbit now accepts incoming connections on port 8444 and asks the router to open that port with UPnP. Settings → Network turns either off. With a proxy set it never listens.

## Fixes

- A letter could make the reader show a file from your disk by naming it as a picture. It no longer can.
- ynotbit's own signature line alone now marks a letter as Markdown.
- The Outbox shows only while letters wait in it, and the chan rail no longer blinks when you switch chans.
