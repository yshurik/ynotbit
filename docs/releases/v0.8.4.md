## Fixed

- **Mailbox on another drive on Windows.** Creating or opening a mailbox on a drive other than C: stopped the node with "Error creating directory C:: Permission denied". Drive prefixes are no longer created as folders, and "Permission denied" is accepted where the folder already exists (#5).
- **Drives without file locking.** On a network share or a VM's shared folder, creating a mailbox said "database is locked". It now says that the location does not support the file locking a mailbox needs, and to choose a folder on a local drive. Opening an existing mailbox there still shows the raw error.

## Changed

- **New mailbox next to the vault.** The Create mailbox dialog opens in the vault's folder, with a name made from the vault's name. New vault starts in the folder of the current vault.
- **Errors stand out.** The error line under the header has an amber background in both themes.
- **Flatpak.** The Flatpak is built with the project's own CMake install rules, and secp256k1 and miniupnp are git submodules of the repository.

## Also

- `scripts/build-windows.ps1` builds ynotbit on Windows in one step (MSVC, Ninja, vcpkg, Qt), optionally packaging a zip.
- The new message is translated into all six languages by hand and not yet proofread by a native speaker.
