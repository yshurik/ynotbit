## New

- **Channels have names.** A channel is `#name`. One dialog joins either kind: a public channel takes its name from the shared phrase, a secret one has a name of your own and a phrase typed hidden, with an eye to show it. Channels already in a vault are renamed once when it opens (`[chan] bitmessage` becomes `#bitmessage`).

## Faster

- **Long chats.** A chat shows its newest 100 messages and brings in 25 more as you scroll up, without moving what you are reading. Opening a chat of 1000 messages takes about 60 ms; before, every update rebuilt the whole thread and froze the window for over a second.

## Network

- **TLS between nodes.** ynotbit now switches to TLS with peers that offer it, with the settings PyBitmessage uses, so a passive observer on the path no longer sees the traffic or which objects you sent first. It does not authenticate the peer. Peers without TLS stay on plain TCP. Tested against PyBitmessage 0.6.3.2 and MiNode 0.3.3.
- **A busy port no longer stops the node.** If another program holds port 8444, the node listens on a port the system picks, tries 8444 again every 15 minutes, and says so in the status line.
- **A node outlives no window.** A window killed outright used to leave its node running with the port and the object store held, and the next window could only say "Node stopped". A node now quits when its window is gone, the status line says why a node stopped, and the window starts it again after 30 seconds.
- MiNode peers no longer drop every few minutes: an `addr` that counts one entry more than it carries keeps the connection.
- On Windows a port held by another program is now seen as taken, so the fallback works there too, and the IPv6 listener takes IPv4 connections as well.

## Fixes

- **Chats are kept.** A chat message was deleted 24 hours after it was sent, and a backup left chats out. Twenty-four hours is how long the network holds a chat; your mailbox keeps it now, and a backup holds your chats.
- **Each list collapses on its own.** The button that collapses the list on the left of Chats, Channels and Subscriptions worked on all three at once. Each page keeps its own now, so channels can be compact beside an expanded chat list. If you had collapsed the list before, all three start collapsed.
- The dialog that joins a channel keeps its width from public to secret.
