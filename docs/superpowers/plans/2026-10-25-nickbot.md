# nickbot implementation plan

Spec: `docs/superpowers/specs/2026-10-25-nickbot-design.md`. Work happens on `main`, uncommitted until the user says `ci`. Every task is test first: write the test, watch it fail for the right reason, write the code, watch it pass. A task is ticked only after its gate has been run and read.

Order: the Go bot first (it needs nothing from the app), then the C library hook it needs, then the app's core, the session, the UI. Each phase leaves the tree building and its tests green.

## Phase A: the service (Go, no cgo yet)

Module `nickbot/` (`github.com/yshurik/ynotbit/nickbot`, Go 1.24, `modernc.org/sqlite` v1.45.0, nothing else outside the standard library).

- [x] **A1 `internal/nick`**: parse `@ben`/`/bot`/`#chan` into sigil and name; 3 to 32 characters; first character a letter; canonical key (lower case for `@` and `/`, exact for `#`); search term rules (optional sigil, 4 or more of `[A-Za-z0-9_-]`, no more than 32). Table test shared with C++ (the cases live in `nickbot/testdata/nick_cases.txt`, read by both).
- [x] **A2 `internal/bmaddr`**: validate a Bitmessage address (`BM-`, base58, version 3 or 4, stream 1, double-SHA-512 checksum, ripe length), with the three reference vectors of `tests/bmclient/protocol_test.cpp` and bad ones (checksum, alphabet, length, stream 2, upper-case prefix).
- [x] **A3 `internal/store`**: schema and migrations (`user_version`), `Register`, `Unregister`, `ByNick`, `ByAddress`, `Search`, `Release` quarantine, `Seed`, `Handled`/`MarkHandled` in the same transaction as the action, `History`, `Stats`, `Export`, `Prune`, `Backup` (`VACUUM INTO`). Tests for every rule of spec 3.2: one name per sigil per address, replace, idempotent re-register, taken, case-insensitive for `@` and `/` but not `#`, quarantine (only the old owner within 30 days, anyone after), static chan and seeded names, unregister of a name that is not yours, search ordering and the cut at 10, injection corpus, a repeated event id does nothing the second time.
- [x] **A4 `internal/limit`**: token buckets with an injected clock, a bounded map of senders (evicts the least recent), registration quota per 24 hours, global budgets. Tests with a fake clock.
- [x] **A5 `internal/service`**: command parser (chat and letter forms), executor, replies with the trailer, error codes. The sender class (`anonymous` or not) comes in as a parameter. Tests for every command, every error code, the exact trailer JSON, a letter reply without trailer, usage errors, `/nickname` with 1 and 8 and 9 addresses, `/search` with 3 and 4 characters, the `anonymous` refusal.
- [x] **A6 `internal/loop`**: the event loop on an interface `Bot` (`Next`, `Done`, `SendChat`, `SendLetter`, `ChanAddress`, `Status`); notes logged; rate limits applied; handled ids; reply failure leaves the event not done; shutdown on context. A fake `Bot` drives the tests, including the crash between reply and done.
- [x] Gate A: `cd nickbot && go vet ./... && go test -race ./...`.

## Phase B: the C library and the process

- [x] **B1 ABI**: `bmbot_chan_address(const char *phrase, char **address, char **error)` returns the address of the chan the phrase makes (the code of `Vault::addChannel`); declared in `bmbot.h`, implemented in `bmbot.cpp`, covered in `tests/bmbot/abi_test.cpp` (equals `Protocol::channel`) and `ctypes_test.py`. `BMBOT_ABI_VERSION` stays 1 (a function was added, none changed); `bmbot/README.md` says so.
- [x] **B2 `internal/bmbot`** (cgo): `Open`, `Next`, `Done`, `SendChat`, `SendLetter`, `State`, `Status`, `ChanAddress`, `Close`, the event JSON decoded, every returned string freed. Tests (build tag none, skipped when `BMBOT_LIB` is not set): open with a public phrase and a node-less config, address, chan address of `anonymous`, close twice.
- [x] **B3 `cmd/nickbot`**: flags (`--phrase-file`, `--data-dir`, `--seed`, `--public`, `--peer`, `--listen`, `--port`, `--retention-mb`, `--retention-days`, `--log`, `--status-file`, `--anon-phrase`), the status file every 10 seconds with counters, a rotating log without queries, `SIGTERM` stops cleanly, the `admin` subcommands, `--check` for the container healthcheck, daily backup.
- [x] **B4 end to end** (`tests/nickbot/nickbot_e2e_test.py`, run by ctest when Go is present): nickbot over a real `bmnode`; a ctypes client (the `echo.py` class) registers, looks up, searches, and reads the trailers; a chan registration; the anonymous refusal; `SIGTERM`.
- [x] Gate B: `cmake --build build-core` and `ctest --test-dir build-core -R "bmbot|nickbot"` green; the e2e test run by hand once with its log read.

## Phase D: the app's core (Qt-free)

- [x] **D1 `bmc::nickbot`** (`bmclient/include/bmc/nickbot.h`): `Nick` parse and canonical form (same cases file), `std::optional<Reply> parseTrailer(text)` (last line `nickbot: {...}`, `v` 1, fields ignored when unknown), request builders (`address`, `nickname` batch, `search`, `register`), the anonymous phrase constant, validation of a result (nick syntax, address checksum). Core tests.
- [x] **D2 Service folder**: `Delivery::setServiceAddresses(std::set<std::string>)`; `scan` files a message to one of them in folder `Service`; `Mailbox` lists and deletes Service rows without the Trash step (`takeService(limit)` returns and removes in one transaction). Core tests: a message to a service chan lands in `Service`, not in `Channels`, counts nowhere, a message to another chan is untouched; spam to the service chan is removed by `takeService`.
- [x] **D3 chan sender**: `Client::sendServiceChat(from, peer, body, ttl)` (the sender may be a chan, ttl at most the chat life), `Client::sendChat` unchanged. Core tests: refused for an address not in the vault, accepted for a chan, ttl honoured.
- [x] **D4 settings reads**: `Mailbox::settings(prefix)` returning every name and value that starts with it, for the nickname maps. Core test.
- [x] Gate D: `ctest --test-dir build-core` green; `bmclient_tests` count recorded.

## Phase E: the session (Qt)

- [x] **E1 nickbots list**: `Session::nickbots()` (address, label, colour index), `setNickbots`, the built-in default list, limits (5, valid, unique, not own), `nickbotsEnabled`, `autoLookups`; `bm::nickbotColor(i)` with the quote palette plus coral. Widgets tests.
- [x] **E2 the lookup lane**: `ensureLookupChan` (joins `anonymous`, remembers that the app did, refuses when the user has it), `Session::identities()` hides it, `chatConversations()` hides its conversations, `Delivery` told its address on open/unlock. Widgets tests.
- [x] **E3 the engine**: queue per nickbot, scheduler (delay 1 to 10 minutes, 2 minutes between messages to one bot, batches of 8, never within 2 minutes of an identified message), injected clock and random source for tests, processing of `Service` rows each tick (believe only configured nickbots, validate, cache, delete everything), signals `nickLookupFinished`. Tests with canned answers fed into the Service folder.
- [x] **E4 registration**: `Session::registerNickname(identity, nick, bot)`, state in `nickreg:<address>`, state changes from the trailers of chats from the bot; the request waits for a mailbox when the vault is new. Tests: queued chat text, state moves, a taken answer, no answer after 24 hours.
- [x] **E5 contacts**: `nickname:`, `nickbot:`, `nickchecked:` kept; `Session::contacts()` carries the nickbot index; automatic refresh queue; `defaultContacts()` has `/nickbot`; opportunistic cache from public answers. Tests.
- [x] Gate E: `desktop_tests` green.

## Verification at the end

- Mutation checks (a script over single-line breaks) on: ownership of a name, quarantine, chan derivation, the anonymous refusal, the handled-id check, the sender check on answers, the divert predicate, the min-length rule, the colour index.
- An include audit (`iwyu_lite.py`) over the new C++ files against HEAD.
- `clang-format --lines` on changed hunks only; `gofmt -l` clean; `go vet` clean.
- A final read of the diff for stray debug hooks (`grep` for the `*_ONLY` env hooks).
